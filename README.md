# Cat Page 🐱

A simple cat-themed webpage built entirely with **HTML**. The page features cute cat content and a special **Miku button** that takes visitors to **Hatsune Miku's "Hoyo Hoyo"** on YouTube for a fun little surprise :3

## Features

* 🐾 Cat-themed webpage
* 🎵 Miku button that redirects to *Hoyo Hoyo* on YouTube
* 📝 Built using only HTML

## Built With

* HTML5

## What I Learned

While building this project, I practiced:

* Structuring web pages with HTML
* Creating links between web pages and external websites
* Organizing content using basic HTML elements

## Purpose

This project was created as a beginner HTML exercise to practice the fundamentals of web development while making a fun webpage featuring cats and a little Hatsune Miku easter egg :D
